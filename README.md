# 📊 Sales Dashboard

An interactive sales dashboard built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

https://romitpatel4.github.io/sales-dashboard/

## 🚀 Features

- Total sales calculation
- Total orders calculation
- Average order value
- Best-selling product
- Category filtering
- Dynamic sales table
- Responsive design

- HTML5
- CSS3
- JavaScript
